# Learning Roadmap

My roadmap for preparing for college and building programming skills before summer 2027.

This is a flexible plan, not a strict deadline. Math is my main priority, with programming alongside it.

## 1. Math — Highest Priority

- [ ] Review foundational algebra skills
- [ ] Strengthen geometry fundamentals
- [ ] Learn Algebra II
- [ ] Study functions and graphing
- [ ] Learn trigonometry
- [ ] Work through precalculus
- [ ] Begin calculus when ready
- [ ] Explore probability and statistics

**Resources:** Khan Academy, *Precalculus: An Investigation of Functions*

## 2. Python — Main Programming Focus

- [ ] Variables, types, and operators
- [ ] Conditions and loops
- [ ] Functions and scope
- [ ] Lists, tuples, dictionaries, and sets
- [ ] Strings and file handling
- [ ] Exceptions and debugging
- [ ] Modules and packages
- [ ] Object-oriented programming
- [ ] Solve practice problems
- [ ] Build small projects

## 3. C++ — Continue Building Fundamentals

- [ ] Review variables, types, and control flow
- [ ] Understand functions and references
- [ ] Practice pointers and memory management
- [ ] Learn classes and object-oriented programming
- [ ] Work with the standard library and containers
- [ ] Study algorithms and data structures
- [ ] Solve programming problems
- [ ] Build small projects

**Standard:** C++20

## 4. Java — Optional

- [ ] Learn basic syntax and types
- [ ] Practice conditions, loops, and functions
- [ ] Learn classes and object-oriented programming
- [ ] Explore collections
- [ ] Build a small project

Start when my math and primary programming routine is established.
